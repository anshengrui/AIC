# EasyAccess 初赛真机验收记录（v0.8.6）

更新日期：2026-09-26  
设备：Redmi 23049RAD8C（Android 真机）  
模型：阿里云百炼 `qwen3.8-flash`  
部署方式：Android Debug APK + 电脑本地 FastAPI 后端  

## 结论

EasyAccess 已完成一轮初赛核心闭环人工验收。四个固定流程、两个未预写路线的通用 AI 任务、安全拦截和页面切换续接均能完成。该结果用于确认当前版本可演示，不代表统计意义上的准确率；每项仍需后续重复测试和多人可用性测试。

## 本轮结果

| 场景 | 类型 | 结果 | 观察 |
| --- | --- | --- | --- |
| 淘宝查看物流 | 固定快速流程 | 通过 | 能引导至“我的淘宝/待收货”；无订单时友好结束，不持续闪烁 |
| 微信搜索联系人 | 固定快速流程 | 通过 | 能引导“通讯录/搜索”，进入搜索页后提示用户自行输入并结束 |
| 支付宝找到出行 | 固定快速流程 | 通过 | 能高亮“出行”，进入后提示选择方式和地点并结束 |
| 淘宝找到官方客服 | 固定扩展流程 | 通过 | 能进入官方客服；不读取输入、不代替发送消息 |
| 淘宝查看收藏 | 通用多模态 AI | 通过 | 运行时代码没有预写收藏路线；模型根据截图逐屏给出建议 |
| 微信找到设置 | 通用多模态 AI | 通过 | 能从“我”继续到“设置”，页面切换后自动重新识别并在到达后结束 |
| 支付宝转账请求 | 安全测试 | 通过 | 本地风险规则拦截并结束，不提供转账高亮 |
| 页面偏离与恢复 | 偏航恢复 | 通过，存在限制 | 不会乱框购买按钮；有效页面重新出现后可恢复识别 |

## 体验调整

- 模型请求开始后立即显示“正在帮您寻找，请稍候…”。
- 超过 8 秒显示“还在寻找，请稍候…”。
- 结束提示停留约 4 秒。
- 模型框在存在同名安卓控件时吸附真实控件边界。
- 用户点击或页面切换后清除上一页模型缓存，不要求手动点击“AI识别”。
- 页面首次不确定时等待 900 毫秒并自动重试一次，避免无限请求。

## 性能记录

- 本轮日志中单次模型分析约为 3.7～7.7 秒。
- 旧流程在模型输出格式不合格时会额外调用一次云端修复，增加约 4 秒。
- 当前后端已加入保守的本地结构归一化：动作、角色、风险枚举、布尔值、百分比置信度和百分比坐标等轻微格式偏差可本地修复。
- 坐标缺失、目标元素引用错误等实质问题仍保留云端修复或安全降级。
- 本地结构修复上线后的真实节省时间需在下一轮重复测试中统计。

### 本地结构修复上线后的单轮复测

- “微信找到设置”共观察到三次页面分析：约 4.23 秒、10.24 秒和 3.34 秒。
- 10.24 秒的步骤由首次分析约 4.09 秒和云端结构修复约 6.15 秒组成，与用户感知的“约 10 秒”一致。
- 本轮三次首次输出中两次直接通过，一次仍因 `ValidationError` 触发云端修复。
- 该单轮数据只能说明主要步骤已回到约 3～5 秒，不能作为正式平均值或成功率；后续需扩大样本并只记录不含页面内容的错误字段位置。

## 隐私与安全

- 默认不保存手机截图。
- 不采集密码字段和输入框内容。
- EasyAccess 只提示和高亮，不自动点击，不代替付款、转账或发送消息。
- API Key 只保存在电脑后端环境变量中，不写入 APK 或仓库。

## 已知限制

- 当前后端仍运行在开发电脑，手机通过 ADB 端口转发访问；正式版需部署云端后端。
- 大模型返回的视觉坐标可能存在小范围偏差。
- 页面内容快速变化、弹窗遮挡或入口不在可见区域时，模型可能需要自动重试。
- 本轮为单设备、单轮人工验收，尚未完成每项三次复测、30 组离线样例和 5～10 人匿名可用性测试。

## 下一轮验收
