# 第一里程碑测试计划

## 自动化测试

| 范围 | 用例 | 期望 |
| --- | --- | --- |
| bbox 校验 | 合法、越界、零面积 | 仅合法坐标允许高亮 |
| 风险规则 | 普通入口、通讯录、转账/验证码 | 分别为低、高、严重；高风险确认、严重停止 |
| Mock 引擎 | 三种模式 | 结构一致，语言粒度有差异 |
| 反馈 | done、not_found、unexpected_page、wrong_action | 状态和步骤按规则更新 |
| 上传 | PNG/JPG、错误类型、空文件、超限 | 合法成功，非法返回 `IMAGE_INVALID` |
| API | 创建 → 分析 → 反馈 → 查询 | 会话 id 一致，状态历史可追踪 |

## 人工验收

1. 载入内置演示图并开始识别。
2. 改变浏览器宽度，高亮仍覆盖同一目标区域。
3. 检查普通/老年/低视力模式的字号与指令差异。
4. 依次触发四类反馈，不出现空白页面。
5. 关闭后端后再次提交，前端显示可理解的错误提示。
