# EasyAccess 初赛功能范围

初赛不是只做三个按钮，而是采用“稳定主演示 + 实用扩展 + AI通用能力”的结构。这样既能保证现场成功率，也能证明产品可以从固定流程扩展到陌生页面。

## 第一层：三个稳定主演示

| App | 老年用户目标 | 当前状态 |
| --- | --- | --- |
| 淘宝 | 查看待收货/物流 | 安卓真机流程已完成 |
| 微信 | 进入通讯录并搜索联系人 | 安卓真机流程已完成 |
| 支付宝 | 找到出行入口并提示选择方式和地点 | 安卓真机流程已完成 |

## 第二层：三个实用扩展

| App | 扩展任务 | 安全边界 |
| --- | --- | --- |
| 淘宝 | 找到官方客服 | 不代替发送消息，不读取聊天输入 |
| 微信 | 调大聊天字体 | 仅修改显示设置，最终选择由用户确认 |
| 支付宝 | 查看账单 | 只查看，不进入转账、付款或验证码步骤 |

扩展任务属于下一个小里程碑，按“淘宝客服 → 微信字体 → 支付宝账单”的顺序实现和真机验收。

## 第三层：AI通用兜底

用户可以说出或输入一个不在固定按钮中的目标。多模态模型读取当前截图，返回结构化页面信息和一个下一步候选；本地规则检查坐标、置信度和风险后才允许显示高亮。

初赛现场应重点展示：

1. 同一任务在页面布局变化后仍能重新识别。
2. 模型不确定时会请求更清晰页面，不会乱框。
3. 遇到转账、验证码或敏感权限时会暂停或停止。
4. 普通模式与老年简易模式的说明文字和语音节奏不同。
