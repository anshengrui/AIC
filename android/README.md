# EasyAccess Android 原型（v0.8）

这是 EasyAccess 的 Android 技术验证工程。它不会持续录屏，而是在用户主动开始帮助后读取无障碍控件；本机规则无法定位时，可经独立授权截取当前屏幕，并调用电脑端多模态模型返回一个安全的下一步。

## 当前范围

- 淘宝：`com.taobao.taobao`
- 支付宝：`com.eg.android.AlipayGphone`
- 微信：`com.tencent.mm`

当前版本会监听窗口状态、窗口内容和滚动事件，在页面稳定后读取控件树。它只在内存中保存最近一次观察结果，不持久化页面内容。

为降低隐私风险，当前实现不会读取密码控件内容，也不会采集普通输入框内的文字。AI 界面识别默认关闭；开启前会明确告知截图将发送到用户配置的电脑后端。后端默认不保存截图，API Key 也不会写入 APK。

## 首次运行

1. 使用 Android Studio 打开 `android/` 目录。
2. 等待 Gradle 同步完成。
3. 在 Android 8.0 或更高版本的真机/模拟器上运行 `app`。
4. 点击“打开无障碍设置”。
5. 找到“EasyAccess 界面辅助”并开启。
6. 按需开启“本机视觉识别”。
7. 选择一个快捷任务，或输入/说出包含淘宝、支付宝或微信的自定义目标。

## AI 界面识别开发测试

1. 在电脑启动 FastAPI 后端，并确认访问 http://127.0.0.1:8000/api/health 返回 model 模式。
2. 通过无线或 USB ADB 连接手机。
3. 执行 adb reverse tcp:8000 tcp:8000，将手机回环地址安全映射到电脑后端。
4. 安装 debug APK：adb install -r app/build/outputs/apk/debug/app-debug.apk。
5. 在 EasyAccess 中点击“同意并开启 AI 界面识别”，阅读说明后确认。
6. 本机规则和 OCR 均找不到目标时，AI 会在后台识别当前界面，随后显示模型返回的高亮和语音指引。

开发版使用 ADB 回环隧道，不将后端端口暴露给局域网。正式版不允许明文网络，发布前应替换为 HTTPS 后端。

## 第一阶段验收标准

- 能检测三个目标 App 的切换。
- 页面变化后约 1 秒内更新观察结果。
- 能读取至少部分可见控件的文字和屏幕坐标。
- 能在至少一个候选控件上显示不可点击穿透的蓝色提示框。
- 无法读取的页面会显示为空，作为后续视觉截图兜底的依据。

## 当前限制

- 不会自动点击任何第三方 App。
- AI 兜底当前依赖电脑运行 FastAPI，并通过 ADB reverse 连接。
- 当前支持四个稳定快捷任务，并支持面向淘宝、支付宝和微信的文字/语音 AI 通用目标。
- 尚未生成经过真机验证的 release APK。

## 安全边界

本阶段只做页面观察和提示，不执行付款、转账、发送消息、删除、授权等动作。后续接入模型时，支付、密码、验证码和隐私授权仍需由本地规则强制拦截。
